# Paradise Nursery

## Project Overview

Paradise Nursery is a React-based plant shopping application that allows users to browse plants, explore product categories, add plants to a shopping cart, and manage their cart quantities.

## Features

- Landing page with company information and a Get Started button
- Plant product listings organized by category
- Product images and prices
- Add to Cart functionality
- Shopping cart with quantity updates and item removal
- Redux Toolkit for cart state management
- Responsive layout for desktop and mobile screens

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Redux Toolkit
- React Redux

## Installation and Setup

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.

## Project Structure

- `src/App.jsx` — Main application and landing page
- `src/AboutUs.jsx` — Company information
- `src/App.css` — Landing page styling and background image
- `src/CartSlice.jsx` — Shopping cart reducer functions
- `src/ProductList.jsx` — Plant product listing
- `src/CartItem.jsx` — Shopping cart page
- `src/store.js` — Redux store configuration

## Purpose

This project demonstrates frontend development, React component design, state management with Redux Toolkit, and basic e-commerce shopping cart functionality.
